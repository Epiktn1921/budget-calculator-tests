# Калькулятор бюджета — тесты

Проекты:
- `BudgetCalculator.Api` — сам сервис (контроллер `BudgetController`, модель `BudgetRequest`)
- `BudgetCalculator.Tests` — xUnit-тесты, ссылается на Api

Запуск тестов:

```
dotnet test
```

## Часть 1

Создала проект xUnit (`dotnet new xunit`), добавила ссылку на основной проект
(`dotnet add reference`). Первый тест `Calculate_100x5_NoInsurance_Returns500`:
100 в день, 5 дней, без страховки — ответ 200 OK и сумма 500. Проходит.

## Часть 2

Написала тест на страховку (100 × 5 со страховкой должно быть 525). На исходном коде он упал:

```
Assert.Equal() Failure: Values differ
Expected: 525
Actual:   2500
```

Ошибка в контроллере: `total *= 5` умножает сумму на 5, а страховка должна быть +5%.

Ещё проверила:
- дни 0 и -3 → 400 Bad Request с текстом ошибки
- 1 день → сумма равна цене за день
- цена 0 → сумма 0
- цена с копейками 99.99 × 3 → ровно 299.97 (`decimal` не теряет копейки)

## Изоляция зависимостей

Расчёт страховки вынесла в отдельный сервис `IInsuranceService` / `InsuranceService`,
контроллер получает его через конструктор (зарегистрирован в `Program.cs`).

В тестах контроллера вместо настоящего сервиса подставляю мок (библиотека Moq).
Так проверяется только логика контроллера:
- без страховки сервис не вызывается (`Times.Never`)
- со страховкой в сервис передаётся 500, и контроллер возвращает то, что вернул сервис
- при неправильных днях до страховки дело не доходит

Сам процент проверяется отдельно в `InsuranceServiceTests`: 500 → 525, 1000 → 1050,
и округление до копеек 301.50 → 316.58.

Итого 12 тестов, все проходят.
